Este repositório contém o código que está sendo desenvolvido para o Trabalho de Conclusão de Curso na Fatec Cotia, sobre otimização de carteira de criptomoedas.
O projeto implementa algoritmos e técnicas para análise e otimização de portfólios de investimento em criptomoedas com:
Análise de dados históricos de criptomoedas
Algoritmos de otimização de carteira
Cálculo de métricas de risco e retorno
Visualização de resultados e gráficos
Simulação de estratégias de investimento

As bibliotecas principais incluem:
pandas, NumPy, matplotlib e seaborn para visualizações, plotly para eventuais
visualizações interativas, cvxpy para a solução das otimizações, yfinance
para aquisição de dados e PyPortfolioOpt para otimização. As rotinas foram
executadas em ambiente local.
